FAQ

よくある質問

香典はいくら包めばよいですか？

故人との関係性で変わります。友人・同僚なら 5,000〜10,000円、親戚なら 1〜3万円、ご家族なら 3〜10万円あたりが目安といわれます。同じ立場の方と足並みをそろえるのが安心です。

香典で避けたほうがよい金額はありますか？

4・9 のつく金額（4,000円、9,000円、4万円など）は「死」「苦」を連想させるため避けるといわれます。また、香典は割り切れる偶数を避けて奇数にするという考え方もあります。

結婚式のご祝儀は3万円が基本ですか？

友人・同僚として一人で出席する場合は 3万円が最も一般的といわれます。ただし披露宴のない会や会費制の場合、学生や親しさの度合いによっても変わります。この表では 3〜5万円の幅で示しています。

相場より少ない金額だと失礼になりますか？

相場は「こうしなければならない」という決まりではなく、迷ったときの手がかりです。無理のない範囲で包むほうが、その後のお付き合いにとって自然なこともあります。

いただいたお返し（半返し）はいくらが目安ですか？

いただいた金額の 3分の1〜半分が目安といわれます。金額と時期はお返し計算機で確認できます。

記録まで残すなら、tsutsum

この相場表は、慶弔記録アプリ tsutsum（ツツム） に内蔵されているものと同じデータです。アプリなら「誰に・いくら・いつ」を記録しておけて、 お返しの目安額と時期も自動で出ます。記録は端末の中だけに保存される完全オフラインです。
