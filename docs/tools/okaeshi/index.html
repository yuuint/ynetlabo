FAQ

よくある質問

お返しはいただいた金額のどれくらいが目安ですか？

3分の1から半分（半返し）が目安といわれます。この計算機もその幅で出します。高額をいただいた場合は3分の1程度に抑えることが多いようです。

香典返しはいつ渡すものですか？

四十九日の法要が済んでから、忌明けの挨拶とあわせてお返しするのが一般的といわれます。当日返し（会葬御礼と一緒に渡す）の地域もあります。

結婚祝いの内祝いはいつまでに返しますか？

挙式から1ヶ月以内が目安といわれます。挙式に出席いただいた方には引き出物がお返しにあたるため、別途の内祝いは不要とされることが多いです。

出産祝いのお返しの時期は？

生後1ヶ月のお宮参りのころが目安といわれます。体調の回復を優先して、少し遅れても差し支えないとされています。

お返しが不要な場合はありますか？

「お返しは気にしないで」と言われた場合や、目上の方から励ましの意味で贈られた場合など、お返しを控えるほうが自然なこともあります。お礼状だけをお送りする形もあります。

「もらいっぱなし」を防ぐなら、tsutsum

慶弔記録アプリ tsutsum（ツツム） は、いただいた記録を残すと、この目安額と時期を自動で計算して「そろそろお返しの時期かも」と控えめに知らせます。 記録は端末の中だけに保存される完全オフライン。5年後に「あの人にいくらいただいたか」も引けます。
