wa/ri アップデート情報 2026/10

2026年9月27日 by yuuint

10月の更新内容をまとめます。v2.09 から v2.12 までの変更です。

  1. メンバーの記録が、通知で届くようになりました（v2.12）
  2. 届いたお知らせを、ルームごとに見返せます（v2.12）
  3. オーナーが割り方を決めて、記録を確定できます（v2.11）
  4. 「画像で共有」が画面の下に移りました（v2.11）
  5. アプリのアイコンが新しくなりました（v2.09・v2.10）
  6. ルーム一覧とルーム画面の見た目を新しくしました（v2.09）
  7. 飲食店のレシートが読み取れなかった不具合を直しました（v2.09）
  8. Android 版・Web 版を iOS 版にそろえました

1. メンバーの記録が、通知で届くようになりました

旅行や飲み会のあいだに、ほかのメンバーが記録を足したことに気づけるよう、通知でお知らせします。

届くとき通知の例タップすると
メンバーが記録を足したときイワトビさんが「夕食」¥3,200 を記録しましたそのルームの記録の一覧が開き、足された記録が少しの間光ります
オーナーが割り勘を確定したとき割り勘が確定しました（合計 ¥9,800）そのルームの割り勘結果が開きます
wa/ri からのお知らせ新機能やキャンペーンのお知らせ（音は鳴りません）お知らせの本文が開きます
  • 続けて記録したときは、2分ごとに1通にまとめて届きます。何件も続けて鳴ることはありません
  • 自分が記録・確定したものは、自分には届きません
  • アップデート後に初めて開くと、「メンバーの記録が届きます」のページが1枚だけ出ます。「通知を設定する」を押すと、端末の通知の許可を聞かれます
  • 種類ごとのオン／オフは、設定 → 通知 で切り替えられます。はじめは記録の追加と割り勘の確定がオン、お知らせはオフです
  • アプリのアイコンに数字のバッジは付きません

2. 届いたお知らせを、ルームごとに見返せます

ルーム一覧の右上にベルが増えました。開くと、ルームの記録の追加・確定と、wa/ri からのお知らせが並びます。

  • 旅行のあいだは記録が多くなるので、ルームごとに束ねて、新しい動きのあったルームが上に来るようにしました
  • 各ルームは新しい順に3件まで。それより多いときは「すべて見る」から全部見られます
  • 未読があるとベルに点が付き、一覧を開くと消えます
  • 通知を切っている人の一覧にも溜まります。通知の設定は「鳴らすかどうか」だけを決めます
  • 一覧に出るのは、この90日の分です

お知らせ一覧は Web 版（ブラウザ・LINE から開く wa/ri）にも入りました。Web 版には通知は届きませんが、ルーム一覧のベルから同じ一覧を見られます。

3. オーナーが割り方を決めて、記録を確定できます

割り勘結果の「まとめる」をオンにするかどうかで、払う相手と金額が変わります。 これまでは各自の画面での切り替えだったため、メンバーごとに違う割り方を見たまま送金してしまうことがありました。 そこで、ルームオーナーが割り方を決めて記録を確定するようにしました。

  • 割り勘結果の画面下に、オーナーにだけ「記録を確定する」が出ます
  • 押すと「まとめない」「まとめる」を選ぶシートが開き、それぞれの送金回数を見比べてから確定できます。選ぶと後ろの割り勘結果もその割り方に切り替わります
  • 確定中は、メンバー全員の割り勘結果がその割り方で表示されます。結果の上には「『まとめる』の割り方で精算してください」のような案内が出ます
  • メンバーの画面では、ボタンの代わりに「未確定：オーナーの確定待ち」のような札が出ます
  • ルームの設定の「記録を確定する」でも、割り方を選べるようになりました
  • 「確定を解除する」で、記録の編集と割り方の切り替えが戻ります

画像で共有したときと PDF にも、確定した割り方が入ります。

4. 「画像で共有」が画面の下に移りました

割り勘結果の「画像で共有」を、画面下の「記録を確定する」の右隣に移しました。 iOS 版・Android 版・Web 版のすべてで同じ位置です。

5. アプリのアイコンが新しくなりました

紫の背景に、白い人型ふたりとオレンジのコインを置いたデザインに変えました。 人型の胴体にはやわらかい影を入れ、コインは真円に整えています。

iOS 26 のホーム画面では、ガラスのような光沢と奥行きのあるリキッドグラスのアイコンになります。 コインがひとつ奥に重なって見え、端末を傾けると縁の光り方が変わります。 ダークモードでも紫の背景はそのまま残り、ホーム画面を「クリア」や「色合い」にしている場合はその設定に合わせた色で表示されます。

6. ルーム一覧とルーム画面の見た目を新しくしました

ルーム一覧

  • 左上に、アプリのアイコンと名前が並びます。起動すると、スプラッシュのアイコンがそのまま左上まで飛んでいきます
  • 新規作成・エール・ヘルプのボタンを、画面上部の1列にまとめました。一覧を下へ読み進めても、この列は残ります
  • 一覧の下にあった広告は、ルームが1件以上あるときは上部の横長の枠に移ります。下へ読み進めると上へ隠れ、上へ戻すと降りてきます
  • 広告の枠の上に出していた「広告」の見出しはなくしました

ルーム画面

  • 合計のカードを、書類をはさんだフォルダの形にしました。右上の切れ込みから書類が3枚のぞいていて、いちばん手前の書類に記録の件数が書かれています
  • 参加しているメンバーのアイコンは、右から順に時間差で出てきます
  • ルーム情報のカード、合計のカード、ボタンの間が空きすぎていたので詰めました

動きは、端末の「視差効果を減らす」を入れていると止まります。

7. 飲食店のレシートが読み取れなかった不具合を直しました

v2.06 で入れたレシートの読み取りで、居酒屋などのレシートが明細0件になることがありました。 金額の後ろに外税の印（「外」）が付く書き方を、読み取れていなかったためです。

あわせて、飲食店でよく見る書き方にも対応しました。

  • 品名と「@単価×数量　金額」が別の行に刷られている形
  • 金額の後ろに「10%」のような税率が付く形
  • 合計が「お会計」「ご請求」「総額」と書かれている形

スーパー・コンビニ・居酒屋のレシート6種で、取り込んだ明細の合計がレシートの合計と合うことを確かめています。

8. Android 版・Web 版を iOS 版にそろえました

Android 版

  • 画面の文字を Noto Sans JP にしました。 これまでは端末の書体で表示していたため、機種によって見え方が大きく違っていました
  • 起動したときのスプラッシュが、iOS 版と同じペンキの絵になります
  • ルーム一覧に「フィルターと並び替え」が増えました。確定済みのルームを隠す設定と、並び順（ルーム作成順／ルーム名順）を選べて、次に開いたときも残ります
  • ルームの設定の下から、支払い記録を CSV / PDF で出力できるようになりました

Web 版

  • ルーム一覧のヘッダーと「フィルターと並び替え」、ルーム画面のフォルダ型の合計カードを iOS 版にそろえました
  • 割り方を決めて確定する流れと、お知らせ一覧も入っています

そのほか

  • ルームを作った直後に共有リンクのメニューを開くと、中身が空になることがあった不具合を直しました（iOS 版）

使い方ガイドも更新しました

通知とお知らせ一覧、割り方を決めて確定する手順を、使い方ガイドに足しました。

  • wa/ri 使い方ガイド（「19. 通知とお知らせ一覧」「9. 割り勘結果を見る」）
  • アプリ内の使い方ガイド（通知とお知らせ）

ご利用にあたって

  • 通知は iOS 版・Android 版の機能です。Web 版には届きません。
  • 割り方を選ぶ前の古いバージョンで確定したルームは、割り方が決まっていません。オーナーには「割り方を指定する」のご案内が出ます。
  • リキッドグラスのアイコンは iOS 26 以降で表示されます。
  • Android 版は書体を同梱したため、アプリの容量が少し増えます。
  • 割り勘の計算のしかたや、記録のデータは変わりません。

前回までの更新内容は、9月のアップデート情報にまとめています。
