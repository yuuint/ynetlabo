慶弔記録アプリ

tsutsum

ご祝儀・香典・お見舞いの「誰に・いつ・いくら」を、一生モノの記録として端末に残すアプリです。記録して終わりではなく、お返しの管理までカバーします。

For

こんなときに

  • 冠婚葬祭のたびに「前にいくら包んだっけ」と探している人
  • いただいたお返しを、うっかり忘れたくない人
  • 金額の記録をクラウドに置きたくない人
Features

できること

贈った・もらったを、そっと一冊に

結婚・出産・入学・新築・葬儀・法要・お見舞いなど、名目ごとに金額または品物を記録できます。時系列のタイムラインで、いつ何があったかを追えます。

相手ごとの、お付き合いが見える

人物別に贈受の履歴と収支をまとめて見られます。「あの人には何をいただいて、何を返したか」が5年後でも引けます。

お返しの目安額と時期

いただいた金額から半返し（3分の1〜半分）の目安を計算し、四十九日明け・お宮参りのころなど、名目ごとの自然な時期を控えめに知らせます。急かす通知は出しません。

関係性別の相場表を内蔵

「いくら包めばいいか」に、名目 × 関係性の幅で答えます。オフラインで開けるので、式場や斎場でもそのまま見られます。

記録は端末の中だけ

完全オフライン設計です。サーバーにもアカウントにも預けません。機種変更に備えて、手動バックアップと復元に対応しています。

連名・住所・書き出し

「○○一同」の人数割りに対応。香典返しの発送先も残せます。記録は PDF に書き出せます。

FAQ

よくある質問

アカウント登録は必要ですか？

不要です。tsutsum は完全オフラインで動き、記録は端末の中だけに保存されます。サーバーには送られません。

香典はいくら包めばよいですか？

関係性で変わります。友人・同僚なら 5,000〜10,000円、親戚なら 1〜3万円あたりが目安といわれます。アプリ内の相場表と、Web の相場早見表で確認できます。

お返しはいくらが目安ですか？

いただいた金額の3分の1〜半分（半返し）が目安といわれます。アプリが自動で計算し、お返し計算機でも同じ目安を確認できます。

機種変更したらデータはどうなりますか？

手動バックアップから復元できます。iOS は iCloud の OS バックアップ、Android は書き出したファイルの持ち運びに対応しています。

無料で使えますか？

はい。記録・お返し管理・相場表・バックアップは無料で使えます。記録できる件数の上限もありません。
