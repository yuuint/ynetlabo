割り勘計算アプリ

wa/ri

旅行や飲み会の支払いをその場で記録しておくと、「誰が誰にいくら払えば終わりか」を計算します。結果だけでなく、そこに至る計算過程まで表示するのが wa/ri です。

  • iOS
  • Android
  • Web（PWA）
  • LINE（LIFF）
App Store で入手 Google Play で入手 Web 版を開く
For

こんなときに

  • 旅行の立て替えが複雑になって、あとで揉めたくない人
  • 「なんでこの金額？」に説明できる形で精算したい幹事
  • 海外旅行で、現地通貨と円が混ざる精算をしたい人
Features

できること

計算過程が見える

「A さんが B さんに 3,200 円」という結果だけでなく、どの支払いがどう相殺されてその金額になったかを追えます。結果だけ出されても信用できない、という不満に応えた設計です。

登録なしで始められる

ルームを作って人数を入れれば、その場で使えます。アカウントは、複数端末で共有したくなってから作れば大丈夫です。

招待して、みんなで記録

招待リンクを渡すと、各自が自分の支払いを記録できます。幹事ひとりが全部を打ち込む必要がありません。

レシートをカメラで読み取る

レシートを撮ると金額を読み取ります。会計のたびに手入力しなくて済みます。

外貨ルーム

米ドル・ユーロなどの外貨で記録して、最後に円で精算できます。海外旅行の「現地で払った分」もそのまま入れられます。

集金の記録と、CSV / PDF 出力

「誰が精算を済ませたか」まで追えます。結果は CSV / PDF に書き出せるので、グループに共有したり手元に残したりできます。

FAQ

よくある質問

無料で使えますか？

はい。ダウンロードも利用も無料です。アカウント登録なしのゲストのままでも、ルームを作って割り勘の計算まで行えます。

アプリを入れずに使えますか？

Web 版（PWA）と LINE 版があります。相手にアプリを入れてもらわなくても、招待リンクから参加してもらえます。

端数はどう処理されますか？

端数の扱いも計算過程の画面で確認できます。誰がいくら多く負担しているかが見えるので、その場で調整できます。

海外旅行で使えますか？

外貨ルームに対応しています。米ドル・ユーロなどで記録して、最後に円換算で精算できます。
