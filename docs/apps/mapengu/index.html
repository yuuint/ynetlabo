ペンギン検索アプリ

mapengu

日本国内でペンギンと出逢える水族館・動物園を、地図とアルバムから探せるアプリです。カメラを向けるだけで種類を見分ける、ペンギン判定カメラも入っています。

  • iOS
  • Web
App Store で入手 Web 版を開く
For

こんなときに

  • 旅行先の近くでペンギンに会える場所を探している人
  • 水族館で見たペンギンの種類が知りたい人
  • 特定の種類のペンギンに会いに行きたい人
Features

できること

地図から探す

日本地図から、ペンギンを飼育している施設を探せます。旅行先の周辺で会える場所がすぐわかります。

ペンギン判定カメラ

スマホをペンギンに向けると、種類をその場で判定します。判定結果から、その種類を飼育している施設の検索にそのまま進めます。端末の中で推論するので通信は要りません。

アルバムからマッチング

写真の一覧から気になるペンギンを選ぶと、その種類に会える施設が見つかります。名前を知らなくても探せます。

FAQ

よくある質問

無料で使えますか？

はい。ダウンロードも利用も無料です。

判定できるペンギンの種類は？

日本国内の施設で飼育されている主要な種類に対応しています。判定の仕組みは技術記事で詳しく解説しています。

Android 版はありますか？

現在は iOS 版のみです。Web サイトからは、どの端末でも施設を探せます。
