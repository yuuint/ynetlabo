よくあるお問い合わせ

お問い合わせフォームやメールでいただいたご質問のうち、多かったものをまとめました。お問い合わせの前に、こちらもご覧ください。

wa/ri（割り勘アプリ）お問い合わせについて

wa/ri（割り勘アプリ）

ルームが急に見られなくなりました。元に戻せますか？

まず、次のどれに当てはまるかを確かめてください。

  • 「表示しようとしているルームにアクセスできません」と出る … そのルームを見る権限がなくなっています。ルームのオーナーに招待リンクを送り直してもらってください。
  • アカウントを作らずに（ゲストのまま）使っていた … ゲストのデータはその端末の中だけにあり、一定期間で消えることがあります。ほかの端末やブラウザからは見られません。
  • 招待された側だった … オーナーがルームを削除した可能性があります。オーナーに確かめてください。
  • 「読み込めませんでした」と出る … 電波が弱いか、サーバーが混み合っています。電波の届く場所で「もう一度読み込む」を押してください。

ルームの削除はオーナーだけができ、元に戻せません。削除されたルームを運営側で復元することもできません。

記録が消えたときのために、手元に残しておけますか？

できます。割り勘結果の画面から CSV または PDF に書き出して、端末に保存できます（使い方ガイド 18章）。

旅行や飲み会が終わったら、精算する前に一度書き出しておくのがおすすめです。万が一ルームが見られなくなっても、誰がいくら立て替えたかが手元に残ります。

機種変更しても、ルームは残りますか？

アカウントを作っておけば残ります。新しい端末でログインすると、これまでのルームがそのまま開きます。

ゲストのまま使っていると、データは前の端末の中だけにあり、新しい端末には移せません。機種変更の前に、マイページでアカウントを作るか、LINE・Apple と連携しておいてください（使い方ガイド 23章）。

LINE との連携を外したい

LINE アプリの設定から外せます。

  1. LINE アプリで 設定 → アカウント → 連動アプリ を開く
  2. 一覧から 「Y.Netlabo」 を選ぶ
  3. 連動を解除する

外すのは、wa/ri に LINE でログインしていた本人の LINE アプリからです。家族や友だちが自分の LINE でログインしていた場合は、その人に外してもらってください。

LINE と連携したときに保存している情報は、Y.NetLaboアカウント「アカウントに保存する情報」にまとめています。

退会して、データを消したい

wa/ri の マイページ →「削除して退会」 から退会できます。2段階の確認のあと削除され、元に戻せません。

  • 自分がオーナーのルーム … ほかのメンバーが付けた記録も含めて、ルームごと削除されます。
  • 招待されて参加していたルーム … ルームは自分の一覧から消えますが、そのルームに追加した記録は削除されません。記録を消すと、ほかのメンバーの割り勘の金額が変わってしまうためです。オーナーとほかのメンバーは、そのまま精算を続けられます。

LINE でログインしていた場合は、

  1. 先に wa/ri で「削除して退会」をする
  2. そのあとで、LINE の連動アプリから「Y.Netlabo」を解除する（上の手順）

の順にすると、LINE から wa/ri に連携されていたユーザー名などの情報も含めて削除されます。

画面ごとの操作は wa/ri 使い方ガイド にあります。

お問い合わせについて

お問い合わせのとき、何を書けばいいですか？
  • お問い合わせID … アプリのマイページ（アカウントメニュー）の下に出ています。タップでコピーできます。どのアカウントのことかがすぐ分かり、お返事が早くなります。
  • メールアドレス … フォームの「ご連絡先」は任意ですが、空のままだとお返事できません。お返事が必要なときは必ず入れてください。
  • ルームのことなら（wa/ri）… 共有リンク（https://wa-ri.ynetlabo.net/share/…）とルーム名があると調べやすくなります。

パスワードは送らないでください。

解決しないときは

お問い合わせフォームからご連絡ください。お返事が必要なときは、メールアドレスもお書きください。
