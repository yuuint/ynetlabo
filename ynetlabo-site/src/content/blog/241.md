年末の帰省が近づくと、毎年同じことで迷います。
「去年、あの子にいくら渡したっけ」「うちの子はいくらもらったっけ」。

お年玉の金額そのものより、**親戚の間で釣り合っているか**のほうが、あとで気になるものです。
先に年齢別の目安を置きます。釣り合いの話はそのあとです。

### 年齢別の目安

よくいわれる目安です。地域や家ごとに差があります。

| 年齢 | 目安 |
|---|---|
| 未就学（3〜6歳）| 500〜1,000円 |
| 小学校 低学年 | 1,000〜3,000円 |
| 小学校 高学年 | 3,000〜5,000円 |
| 中学生 | 5,000円 |
| 高校生 | 5,000〜10,000円 |
| 大学生・専門学校生 | 10,000円（渡さない家もある）|

0〜2歳の子には、渡さない、または親に「お祝い」として渡す家も多いです。

「学年 × 500円」「年齢の半分 × 1,000円」のような**家ごとの決まり**を作っておくと、毎年迷わずに済みます。

### きょうだい・親戚の間で釣り合わなくなる問題

お年玉で揉めやすいのは、金額の大小よりも **子どもの人数が違う家どうし**です。

| | 兄の家（子ども3人）| 妹の家（子ども1人）|
|---|---:|---:|
| 相手の子に渡す額（1人5,000円）| 5,000円 × 1人 = **5,000円** | 5,000円 × 3人 = **15,000円** |
| 自分の子がもらう額 | 15,000円 | 5,000円 |
| 差し引き | **+10,000円** | **−10,000円** |

1人あたりの額をそろえても、**家どうしで見ると毎年1万円ずつ偏ります。** 何年も続くと、言い出しにくい不満になります。

決め方はいくつかあります。

| 決め方 | 向いている場面 |
|---|---|
| **1人あたりの額をそろえ、偏りは気にしない** | 「子どものためのもの」と割り切れる関係 |
| **家どうしの総額をそろえる**（人数の少ない家の子には多めに渡す）| 偏りを気にする人がいるとき |
| **きょうだい間ではお年玉をやめる**（祖父母からだけにする）| 子どもが増えて負担が大きくなってきたとき |

どれでも構いません。**大人どうしで一度話して、ルールを決めておく**ことがいちばん効きます。
黙って合わせ続けるより、「うちはこうしたい」と年末に一度相談するほうが、長い目で見て楽です。

### ポチ袋のマナー

| | 目安 |
|---|---|
| お札 | **新札**を用意する（銀行の両替機や窓口で。年末は混むので早めに）|
| 入れ方 | お札の表（肖像のある面）を内側にして、左、右の順に**三つ折り**にして入れる |
| 名前 | 表に**相手の子の名前**、裏に**自分の名前**を書く。小さい子には親が分かるように |
| 硬貨 | 500円玉などは表を上にして入れる |
| 目上の家の子に渡すとき | 「お年玉」ではなく「**お年賀**」と書き、文具などの品物にする考え方もある |

### 喪中のとき

お年玉は「新年のお祝い」ですが、**子どもへのお小遣い**として渡すのは問題ないとされます。

- ポチ袋は**お祝いの柄を避け**、無地か落ち着いた柄にする
- 表書きは「お年玉」ではなく「**おこづかい**」「**文具代**」にする
- 渡すときも「おめでとう」は言わない

### いつまでに渡すか

**松の内**（関東は1月7日、関西は1月15日ごろ）までに渡すのが一般的です。
それを過ぎて会うときは「お年玉」ではなく「おこづかい」として渡します。

### 「誰に・何歳で・いくら」を残しておく

お年玉は毎年のことなのに、**記録を残している人はほとんどいません。**
そのせいで、毎年同じことを考え直すことになります。

残しておきたいのは、この3つです。

- **渡した相手と、その子の年齢と、金額**（来年は1歳上がる）
- **自分の子がもらった相手と金額**（相手の子に返すときの目安）
- **家どうしの差し引き**（偏りが続いていないか）

慶弔記録アプリ [tsutsum](/apps/tsutsum/) には「お年玉」という名目はありませんが、
**ギフト → その他の贈り物**で記録できます。

- 渡したお年玉は「**贈った**」、子どもがいただいたお年玉は「**もらった**」で記録します
- 相手は親戚の家ごとにまとめても、子ども1人ずつにしても構いません。**メモに年齢**を書いておくと、来年の目安になります
- 相手ごとに「**包んだ・もらった**」の合計が出るので、家どうしの差し引きがひと目で分かります（[相手の情報を見る](/guide/tsutsum/#person-detail)）

記録は端末の中だけに保存され、サーバーには送られません。家族の金額をクラウドに置きたくない人にも向いています。
