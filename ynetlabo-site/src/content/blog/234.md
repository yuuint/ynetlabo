## 1. ルームに「イベント日」を決められるようになりました<span class="badge-soon">予告：iOS・Android</span>

ルームの作成と設定に「**イベント日**」が増えました。旅行や飲み会の日付をルームに持たせておけます。

| 選べるもの | 意味 |
|---|---|
| 単数日 | 1日だけのイベント（初めは今日） |
| 複数日 | 開始日〜終了日の旅行など |
| なし | 日付を決めない（これまでと同じ） |

- ルーム一覧の行の右に、「**進行中**」「**あと◯日**」「**終了**」の札が出ます。進行中は緑で目立つようにしました
- 行の2行目は、**日付 → オーナー名**の順に並びます。これまで出していた「参加者／管理者」の表示はなくしました
- 「フィルターと並び替え」に「**イベント開始日順**」が増えました。進行中 → 開始前 → 終了・確定済みの順に並びます
- イベント日を決められるのはルームオーナーです。メンバー全員に同じ日付が見えます
- 確定したルームには札を出しません

イベント日は **iOS 版・Android 版・Web 版**のすべてで使えます。

## 2. イベント中の合計を、ダイナミックアイランドとロック画面に出せます<span class="badge-soon">予告：iOS</span>

イベント日の間は、そのルームの**合計・件数・最後の記録**をダイナミックアイランドとロック画面に出せるようになりました（ライブアクティビティ）。
アプリを開かなくても、合計がいくらになったか、誰が何を記録したかがわかります。

- ダイナミックアイランドの左に件数、右に合計が出ます。**タップすると記録の追加画面**が開きます
- 長押しで広げると、最後の記録と「記録を追加」「割り勘を見る」のボタンが出ます
- ほかのメンバーが記録すると、**数秒だけ広がって**新しい合計と記録を見せます（音は鳴りません）
- ロック画面には、ルーム名と「2日目 / 3日間・12件」のような進み具合が出ます
- 割り勘が確定すると「確定しました」に変わり、5分後に消えます

**出るとき**

- イベント日の間に、誰かが**新しい記録**をしたときに始まります。準備の日や後日の修正では出ません
- 最後の記録から**4時間**たつか、その日の 24:00 になると消えます。次の記録でまた始まります
- 今日をイベント日にしてルームを作ったときは、記録がなくてもその場で始まります

**使うかどうか**

- 各自が決めるのは「**ライブアクティビティを使う**」の1つだけです。チュートリアル・設定画面・ルームの上部のバナーから選べます。はじめはオフです
- ルームで使うかどうかは、オーナーがルーム画面の「**ルーム管理**」で切り替えます。イベント日を決めて作ったルームは、はじめからオンです
- その日だけ止めたいときは、ロック画面で消してください

## 3. ホーム画面のウィジェットと Siri から記録できます

**ウィジェット「最近のルーム」**

ホーム画面とロック画面に置けるウィジェットを追加しました。最後に記録したルームが前に来ます。

| 大きさ | 中身 |
|---|---|
| 小 | 最近のルームの合計（ルーム画面と同じフォルダの形） |
| 中 | 最近のルーム1件と、「割り勘」「共有」「記録」のボタン |
| 大 | 最近のルーム6件の一覧と「新しいルーム」 |

スマートスタックに入れておくと、この24時間に動いたルームがあるときに前に出てきます。

**Siri・ショートカット**

Siri に話しかけて、ルームを開く・記録を追加する・割り勘の結果を見る・ルームを作る ができます。
アプリ名は「wa/ri」のほかに「**割り勘**」「**ワリ**」でも呼べます。

- 「割り勘に記録を追加」
- 「割り勘の結果を見せて」
- 「割り勘でルームを作る」

よく開くルームは、iOS の「Siriからの提案」にも出るようになります。
置き方と言い方は、アップデート後のチュートリアルの「ホーム画面からすぐ記録」のページでご案内しています。

## 4. つながらないとき・混み合っているときを、ペンギンがお知らせします

電波が弱いときやサーバーが混み合っているときに、これまでは**一覧が空のまま**になったり、**読み込み中のまま止まったり**、「Exception: API 500」のような文字がそのまま出たりしていました。

- 記録の保存・変更・削除に失敗したときは、ペンギンが「**接続できませんでした**」「**ただいま混み合っています**」「**サーバーで問題が起きています**」のように理由をお伝えし、「**もう一度試す**」から続けられます
- ルーム一覧・記録の一覧・割り勘結果が読み込めないときは、「ルームはありません」と見せずに、理由と「**もう一度読み込む**」を出します。前に読み込んだ一覧は消しません
- 起動したときにつながらないときは、理由と「**もう一度つなぐ**」の画面を出します

あわせて、サーバーが混み合っていたときに、**ログインしていた人がゲストに切り替わり、ルームが消えたように見える**ことがあった不具合を直しました。

## 5. ペンギンをドット絵にしました

読み込み中と完了のときのペンギンを、ドット絵に描き直しました。

- 読み込み中は、ジェンツーペンギンが**雪の上を歩きます**
- 記録できたときは、ジャンプして**魚をくわえて**喜びます
- 招待リンクでルームに参加したときは、**2匹が向かい合ってハイタッチ**します
- ペンギンの後ろには、空色の丸い光を置きました

動きは、端末の動きを減らす設定（iOS の「視差効果を減らす」など）を入れていると、ふわっと出るだけになります。

## 6. トップ画面のボタンを画面の下にまとめました

広告の下にあった「**新規作成**」「**エールを贈る**」を、一覧の下に浮かぶ帯へ移しました。
下へ読み進めると帯が小さくなり、上へ戻すと元の大きさに戻ります。ヘルプは右上へ移しています。

- 「新規作成」のボタンの色を濃くして、文字を読みやすくしました
- 右上のアイコンの大きさをそろえ、オーナーだけが押せるボタンなどは**押せないときに灰色**で見せるようにしました

## 7. 通知から開いた記録まで、一覧がスクロールします

通知やお知らせ一覧から記録の一覧を開いたとき、足された記録が光るだけで、**画面の外にあると見つけにくい**ことがありました。
いまは、その記録の位置まで一覧が自動でスクロールします。

## 8. 使いやすさの細かい改善

- ルーム画面のメンバーのアイコンを押すと、**メンバーの設定**に進めるようになりました
- 記録の入力で金額を入れはじめると、「内容は？」の欄が画面の上へ寄り、**メモ欄まで見える**ようにしました（iOS 版）
- ルームを共有するメニューに、招待リンクの **QR コード**を足しました。押すと大きく出ます（iOS 版）<span class="badge-soon">予告：iOS</span>
- ルームを作った直後にも、通知の案内を1回だけ出すようにしました（iOS 版）
- 起動したときの「おかえりなさい、〇〇さん」を、右上のアイコンが少しの間だけ変わる形にしました。起動直後の最初のタップが、案内を閉じるのに使われていたためです（iOS 版）
- ルーム作成のクイックスタートを2段にして、切り替えと人数のボタンを見やすくしました<span class="badge-soon">予告：iOS・Android</span>
- メンバーに出る「未確定：オーナーの確定待ち」の札を、ボタンと同じ大きさの灰色にしました
- スプラッシュとルームを開くときの待ち時間を、iOS 版・Android 版・Web 版でそろえました

## そのほか

- アプリに戻ったとき、広告の枠が空のまま残ることがあった不具合を直しました（iOS 版）
- 一時記録の編集で、カテゴリの一覧が読み込み中のままになる不具合を直しました（iOS 版）
- カテゴリの丸いアイコンで、アイコンと名前が重なることがあった不具合を直しました（iOS 版）
