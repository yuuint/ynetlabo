忘年会、年末年始の旅行、帰省の交通費。12月は立て替えが一気に増える季節です。

割り勘アプリはたくさんありますが、**どれも「誰が誰にいくら払うか」は出してくれます。**
違いが出るのはその手前です。参加者に登録をお願いするか、みんなで入力できるか、飲まなかった人の負担をどう減らすか、外貨をどう扱うか、そして**無料でどこまで使えるか**。

この記事では、日本で使われている割り勘アプリ6つを、その違いで比べます。

> **はじめにお断り**：筆者は、このなかの **wa/ri の開発者**です。
> 公平になるよう、**良い点・気になる点にはすべて出典を付け**、wa/ri の**できないこと**も書いています。
> ほかのアプリについては、**公式サイト・公式ヘルプや FAQ・ストアの説明**を優先し、それで確かめられなかったことだけ第三者の記事を使っています（第三者の記事にはその旨を書いています）。
> 確認日は **2026年11月16日**です（wa/ri の記述は 11月17日に v2.16 に合わせて更新）。料金や機能は変わることがあるので、使う前に公式でも確かめてください。

## 先に結論：どれを選べばいい？

やりたいことから選ぶと、こうなります。

- **同居・カップルで、ずっと続く貸し借り** → Splitwise / レコペイ / wa/ri
- **外貨を円に換算したい・割合や金額で差をつけたい** → タテカリ / Splitwise
- **揉めないように、計算の中身を見せて、全員に同じ結果で精算したい** → wa/ri
- **記録を勝手に書き換えられたくない（見るだけの人を分けたい）** → wa/ri
- **1回の会計を品目ごとに分けたい** → wa/ri（無料）/ Splitwise（Pro）
- **幹事ひとりで計算して、一部の人だけ減額したい** → groupay
- **国内の旅行・飲み会で、全員アプリなし・登録なしで参加したい** → wa/ri / Walica / タテカリ

## 無料でどこまでできる？

6つとも、**無料で割り勘の計算と精算まで**できます。違うのは、無料版にどんな制限があるかです。

- **wa/ri**：**すべての機能が無料**です。アカウントを作らない（ゲストの）ままでも全機能を使えます。**ルームの数にも上限はありません**。広告で運営しています。<span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[2026/08 アップデート情報](/archives/218/)・開発元（筆者）</span>
- **Walica**：無料。会員登録もアプリのダウンロードも不要です。<span class="src">出典：[Walica 公式サイトの説明文](https://walica.jp/)</span>
- **タテカリ**：**完全無料**と公式に書かれています。<span class="src">出典：[タテカリ公式](https://tatekari.site/)</span>
- **Splitwise**：無料版は**1日に追加できる支出が4件まで**（すべてのグループの合計）。上限なし・通貨換算・レシート読み取り・グラフ・検索などは有料の **Splitwise Pro** です。<span class="src">出典：[Splitwise 公式ヘルプ](https://kb.splitwise.com/pro/what-is-splitwise-pro-and-who-can-use-it)</span>
- **groupay**：機能はすべて無料。広告を消すのが **¥100** のアプリ内課金です。<span class="src">出典：[App Store](https://apps.apple.com/jp/app/groupay/id1387267486)</span>
- **レコペイ**：基本無料。ただし無料版で作れる**進行中のイベントは1つまで**で、前のイベントを「完了」にするまで次のイベントを作れません。<span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span> 有料の **レコペイ PLUS** は月額 ¥500・年額 ¥3,600 です。<span class="src">出典：[App Store](https://apps.apple.com/jp/app/id1669984018)</span> 無料版のレシート読み取りは月5回までとするレビューもあります。<span class="src">出典：[アプリブのレビュー（2023年10月）](https://app-liv.jp/lifestyle/all/1044/)</span>

**旅行で1日に何件も記録する**なら、Splitwise の「1日4件」は意外と早く届きます。4人で旅行して、朝食・交通・昼食・入場料・夕食と記録すると、それだけで5件です。

**イベントをいくつも並べて使う**なら、レコペイの「進行中のイベントは1つまで」が効いてきます。たとえば月末の旅行の精算がまだ終わっていないうちに、来週の飲み会を別に記録する、ということが無料版ではできません。

## 選ぶときに見る5つのポイント

### 1. 参加者に何をお願いするか

割り勘アプリで一番の壁は、**参加者全員に登録やインストールをお願いすること**です。
幹事は乗り気でも、参加者には「その日だけのために登録したくない」人が必ずいます。

幹事も参加者も含めて、**インストールと登録が要るか**、**どこから使えるか**を並べるとこうなります。

インストールも登録もいらないのは、**wa/ri・Walica・タテカリ**の3つです。
このなかで wa/ri は、**同じルームにブラウザ・アプリ・LINE のどこからでも入れる**のが違いです。
「幹事はアプリで、参加者はブラウザで、LINE グループの人は LINE から」のように、**一人ひとりが好きな入り口で同じ記録を見て書けます**（詳しくは[下の節](#参加者はリンクだけ幹事と記録する人はアプリで)）。

### 2. みんなで記録できるか

旅行のように**全員がそれぞれ立て替える**場面では、幹事ひとりに入力が集まると大変です。
一方、飲み会のように**幹事が一人でまとめて払う**場面なら、共同編集はなくても困りません。

### 3. 負担の差をどうつけるか

「お酒を飲んだ人だけで割る」「先輩は多めに」「途中参加の人は少なめに」。この**傾斜割り勘**のやり方は、アプリによって違います。

| やり方 | 例 | できるアプリ |
|---|---|---|
| 対象の人を選ぶ | お酒代は飲んだ4人だけで | 6つとも |
| 一人ずつ金額を入れる | Aさん 5,000円… | タテカリ・Splitwise |
| 割合・シェアで決める | 上司 150% | Splitwise |
| 一人だけ減らす | 新人は −1,000円 | groupay |

### 4. 外貨を円に換算してくれるか

海外旅行では、**現地通貨のまま記録して、最後に円で精算したい**ことが多いはずです。
外貨で記録できるだけなのか、**円に自動で換算**してくれるのかで、使い勝手が大きく変わります。

### 5. 無料版の制限と広告

上の「[無料でどこまでできる？](#無料でどこまでできる)」のとおりです。**何で無料にしているか**（広告か、有料プランか）を見ておくと、使っている途中で困りません。

## wa/ri ならではのところ

ここからは開発者として、wa/ri で特に力を入れているところです。

![wa/ri のストア画像（左から：割り勘の対象を選ぶ記録、2種類の割り方、Web と画像での共有）](/images/posts/wari-store-235-a.webp)

### スマホでもタブレットでも。iPhone・Android・Web のどれでも

![wa/ri はスマホ・iPad・Android タブレットのどれでも使える（ストア画像）](/images/posts/wari-devices-235.webp)

wa/ri は、使う端末を選びません。<span class="src">出典：[App Store](https://apps.apple.com/jp/app/wa-ri/id6743655018)・[Google Play](https://play.google.com/store/apps/details?id=ynetlabo.net.wari)・[紹介記事](/archives/186/)</span>

| 端末 | 使い方 |
|---|---|
| iPhone・iPad | App Store のアプリ |
| Android のスマホ・タブレット | Google Play のアプリ |
| パソコンなど | ブラウザ（[Web 版](https://wari-app.ynetlabo.net/)） |
| LINE | LINE の中でそのまま開く |

- **全員がそれぞれの端末で、同じルームを開けます**。iPhone の人、Android の人、パソコンの人が混ざっても、同じ記録を見て書けます
- **1人で端末を使い分けられます**。アカウントを作れば、スマホで記録して、あとでタブレットやパソコンの大きな画面で見返せます <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
- **OS ごとになじむ見た目**。iPhone・iPad 版は iOS らしい見た目、Android 版は Material Design で作っています <span class="src">出典：[紹介記事](/archives/186/)</span>

アプリと Web の両方で使えるのは Splitwise も同じです。そこに **LINE の中からも開ける**ところまで加わるのは、比べた6つのなかで wa/ri だけでした。<span class="src">出典：[Splitwise 公式](https://www.splitwise.com/)</span>

### 参加者はリンクだけ。幹事と記録する人はアプリで

wa/ri は **Web 版だけでも、ルームを作る・メンバーを登録する・記録する・割り勘を確定する、まで全部できます**。アプリのインストールも、アカウントの登録もいりません（開くと自動でゲストとして始まります）。<span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[紹介記事](/archives/186/)</span>

- **入り口は一人ずつ選べる**。幹事や記録する人はアプリで、たまに見るだけの人はブラウザや LINE から、と同じルームに入れます
- **まずブラウザで試して、あとからアプリへ**。アカウントを作れば、ブラウザで作ったルームをそのままアプリで開けます <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>

登録・インストールなしで記録までできるのは、ほかに **Walica**（ブラウザ）と**タテカリ**（ブラウザ・アプリ）です。

### アプリを入れると、もっと楽になる

ブラウザでも最後まで使えますが、**幹事や記録する人はアプリを入れておくと楽です**。iOS 版・Android 版だけの機能があります。

- **メンバーの記録が通知で届く**。「イワトビさんが『夕食』¥3,200 を記録しました」「割り勘が確定しました」が、その場で分かります。続けて記録されても2分ごとに1通にまとまります <span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[2026/10 アップデート情報](/archives/231/)</span>
- **レシートを撮るだけで記録**。合計金額の読み取りに加えて、1枚のレシートから品目・金額・日付・店名をまとめて取り込めます。読み取りは端末の中だけで行い、画像はどこにも送りません <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
- **旅のおわりに PDF レポート**。合計・カテゴリ別の円グラフ・割り方・記録の一覧を、3章立ての PDF にまとめます <span class="src">出典：[2026/09 アップデート情報](/archives/227/)</span>
- **ホーム画面のウィジェットからすぐ記録**。最後に記録したルームの合計が見られ、割り勘・共有・記録へ1タップで進めます（iOS 版・Android 版）。iOS 版は Siri に「割り勘に記録を追加」と話しかけても記録できます <span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[2026/11 アップデート情報](/archives/234/)</span>
- **旅行中の合計を、ロック画面とダイナミックアイランドに表示**。ルームに「イベント日」を決めておくと、その間だけ合計と最後の記録が出て、タップで記録の追加に進めます（iOS 版）<span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[2026/11 アップデート情報](/archives/234/)</span>
- **CSV・PDF で記録を残せる**。Web 版の書き出しは割り勘結果の画像だけです <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>

Web 版は [wari-app.ynetlabo.net](https://wari-app.ynetlabo.net/)、アプリは [wa/ri のページ](/apps/wa-ri/)から入れられます。

### 計算の過程を、その画面で見せる

送金の回数を減らす計算は、wa/ri・Walica・タテカリ・Splitwise・レコペイのどれもしています。
違うのは**確かめ方**です。タテカリとレコペイは計算のしかたを公式に説明していて、Splitwise は記録を表計算ファイルに書き出して確かめられます。<span class="src">出典：[タテカリ](https://tatekari.site/blog/warikan-algorithm/)・[レコペイ公式 FAQ](https://reco-pay.com/)・[Splitwise ヘルプ](https://kb.splitwise.com/balances-and-expenses/how-can-i-double-check-my-balances)</span>

wa/ri は、**割り勘結果の画面に、そのルームの立て替えと相殺の内訳**をそのまま出せます。「この金額、どこから来たの？」と聞かれたら、画面を見せれば済みます。<span class="src">出典：[紹介記事](/archives/186/)・[使い方ガイド](/guide/wa-ri/)</span>

### 割り方をオーナーが確定する

送金の回数を減らす「まとめる」と、支払いのつながりを残す「まとめない」の2つの割り方があり、オーナーがどちらかで**確定すると、全員に同じ結果が出ます**。<span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
Splitwise にも送金をまとめる「Simplify Debts」がありますが、グループの誰でも切り替えられる設定です。<span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/balances-and-expenses/what-is-simplify-debts)</span>

### 編集できる人を分けられる

権限は「オーナー／編集可／閲覧のみ」の3段階です。<span class="src">出典：[紹介記事](/archives/186/)</span>
Splitwise は権限の設定がなく、グループの誰でも記録を編集・削除できます（代わりに変更履歴と通知があります）。タテカリも URL を知っている人は全員編集できます。<span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/groups/can-i-prevent-group-members-from-changing-expenses-or-set-permissions)・[タテカリの使い方ガイド](https://tatekari.site/blog/how-to-use/)</span>

### 1回の会計を明細ごとに分ける

居酒屋の会計で「お酒は飲んだ人だけ、料理は全員」のように、**1回の会計のまま品目ごとに割り勘の対象を選べます**。レシートを1枚撮れば品目と金額をまとめて取り込めます（iOS 版・Android 版）。読み取りは端末の中だけで行い、画像はどこにも送りません。<span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
支払いごとに対象を選ぶことは、ほかの5つでもできます。Splitwise は Pro で、レシートを読み取って品目ごとに割り当てられます。<span class="src">出典：[Splitwise 公式ヘルプ](https://kb.splitwise.com/pro/what-is-splitwise-pro-and-who-can-use-it)</span>

## それぞれのアプリ

### wa/ri（わり）

![wa/ri のストア画像（左から：外貨のルーム、PDF レポート、ルームのトップ）](/images/posts/wari-store-235-b.webp)

**良い点**

- **iPhone・iPad・Android のスマホとタブレット、ブラウザ、LINE のどれからでも、同じルームを使える**。ブラウザなら登録もインストールもいらない <span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[紹介記事](/archives/186/)</span>
- 計算の過程を画面に出せる。割り方をオーナーが確定できる。権限は3段階。1回の会計を明細ごとに分けられる（→「[wa/ri ならではのところ](#wari-ならではのところ)」）
- すべての機能が無料。アカウントを作らなくても全機能を使え、ルームの数にも上限がない。旅行・飲み会・同居の生活費を、ルームを分けて同時に記録できる <span class="src">出典：[使い方ガイド](/guide/wa-ri/)・開発元（筆者）</span>
- 記録を CSV・PDF で残せる（アプリ版）。割り勘結果は画像にして送れる <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
- アプリ版では、メンバーの記録の通知・レシートの明細読み取り・PDF レポート・ホーム画面のウィジェットが使える。iOS 版は、旅行中の合計をロック画面とダイナミックアイランドに出せる <span class="src">出典：[使い方ガイド](/guide/wa-ri/)・[2026/09 アップデート情報](/archives/227/)・[2026/11 アップデート情報](/archives/234/)</span>
- ルームに「イベント日」を決めておくと、一覧に「進行中」「あと◯日」「終了」が出て、イベントの日付順にも並べられる <span class="src">出典：[2026/11 アップデート情報](/archives/234/)</span>
- 実際に渡したお金を「集金」として記録できるので、同じルームを使い続けながら、誰が払い終わったかを追える <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>

**気になる点**

- **割合や金額を指定する傾斜割り勘はできない**。できるのは「対象の人を選ぶ」まで <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
- 外貨は**ルームごとに通貨を1つ選ぶ**形で、**円への自動換算はしない**。選べるのは円・米ドル・ユーロ・英ポンド・韓国ウォン・人民元・台湾ドル・香港ドル・タイバーツ・豪ドルの10通貨 <span class="src">出典：[使い方ガイド](/guide/wa-ri/)・開発元（筆者）</span>
- Web 版ではレシートの読み取り・通知・CSV／PDF の書き出しが使えない（アプリ版だけ） <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
- 電波がないと記録できない（メモとして控える「一時記録」だけは使える） <span class="src">出典：[使い方ガイド](/guide/wa-ri/)</span>
- 広告が出る <span class="src">出典：[2026/08 アップデート情報](/archives/218/)</span>

[wa/ri のダウンロードと詳細](/apps/wa-ri/) ／ [使い方ガイド](/guide/wa-ri/)

### Walica（ワリカ）

ブラウザで開いてURLを送るだけで使える割り勘サービスです。公開されたヘルプが見当たらないため、公式サイトの説明文と第三者の記事で書いています。

**良い点**

- **会員登録もアプリのダウンロードも不要**。立て替えを入力すれば「誰から誰に」「いくら」払えばよいかを、ボタン1つで出す <span class="src">出典：[Walica 公式サイトの説明文](https://walica.jp/)</span>
- 外貨で入力した立て替えを、円に換算して精算できる <span class="src">出典：第三者の比較記事（[WaliPro](https://walipro.jp/column/warikan-app-hikaku-2026/)。WaliPro は競合サービスの運営元）</span>

**気になる点**

- 立て替えごとの負担額は変えられるが、全体の負担割合をまとめて変えることはできない <span class="src">出典：同上（第三者・競合）</span>
- 広告が出る <span class="src">出典：同上（第三者・競合）</span>

### タテカリ

登録・インストールなしで使えるブラウザ型で、iOS・Android のアプリ版もあります。

**良い点**

- **完全無料**。会員登録・ダウンロード不要 <span class="src">出典：[タテカリ公式](https://tatekari.site/)</span>
- **一人ずつの負担額を直接指定**できる <span class="src">出典：[タテカリ公式](https://tatekari.site/)</span>
- **155通貨**に対応し、円に自動で換算 <span class="src">出典：[タテカリ公式](https://tatekari.site/)・[タテカリの使い方](https://tatekari.site/usage/)</span>
- 端数を**1円〜1,000円単位で切り上げ**られる。送金の回数が少なくなるように精算し、計算のしかたも公開している <span class="src">出典：[タテカリの使い方](https://tatekari.site/usage/)・[精算の計算方法](https://tatekari.site/blog/warikan-algorithm/)</span>
- URL を LINE に共有するボタンがある。消した記録を「削除済み記録」から戻せる <span class="src">出典：[タテカリの使い方ガイド](https://tatekari.site/blog/how-to-use/)</span>
- 画面を遮る広告は出さない <span class="src">出典：[タテカリ公式](https://tatekari.site/)</span>

**気になる点**

- 編集の権限は分けられず、URL を知っている人は全員が編集できる <span class="src">出典：[タテカリの使い方ガイド](https://tatekari.site/blog/how-to-use/)</span>
- 画面を遮らない形の広告は出る（サイトが Google の広告を読み込んでいる） <span class="src">出典：[タテカリ公式](https://tatekari.site/)のページ</span>

### Splitwise（スプリットワイズ）

海外で広く使われている割り勘アプリです。同居人やカップルとの**ずっと続く貸し借り**を積み上げる使い方が得意です。

**良い点**

- **金額・割合・シェア数**で分けられる <span class="src">出典：[Splitwise ヘルプ](https://feedback.splitwise.com/knowledgebase/articles/77463-can-i-split-an-expense-by-percentages)</span>
- 送金をまとめる「Simplify Debts」がある <span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/balances-and-expenses/what-is-simplify-debts)</span>
- グループの記録を表計算ファイルに書き出せる。印刷用のまとめで全取引を確かめられる <span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/balances-and-expenses/how-can-i-double-check-my-balances)</span>
- iOS・Android・Web で使える <span class="src">出典：[Splitwise 公式](https://www.splitwise.com/)</span>
- Pro では通貨換算・レシートの品目分け・グラフ・検索が使え、広告も消える <span class="src">出典：[Splitwise Pro](https://www.splitwise.com/pro)</span>

**気になる点**

- 無料版は**1日4件まで**しか支出を追加できない <span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/pro/what-is-splitwise-pro-and-who-can-use-it)</span>
- 無料版は外貨を円に換算しない（通貨ごとに残高が分かれる） <span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/balances-and-expenses/how-can-i-manage-a-friendship-or-group-with-multiple-currencies)</span>
- 権限の設定はなく、グループの誰でも記録を編集・削除できる <span class="src">出典：[Splitwise ヘルプ](https://kb.splitwise.com/groups/can-i-prevent-group-members-from-changing-expenses-or-set-permissions)</span>
- 参加者もアカウントを作って使う。Pro の日本円の価格は公式ページに書かれていない（アプリ内で確認） <span class="src">出典：[Splitwise 公式](https://www.splitwise.com/)・[Splitwise Pro](https://www.splitwise.com/pro)</span>

### groupay（グルーペイ）

幹事が一人で計算するためのアプリです。iOS 版と Android 版があります。<span class="src">出典：[開発元のサイト](https://broad-connect.net/apps/)</span>

**良い点**

- 支払いごとに**対象のメンバーを選べる**。遠くから来た人・途中参加の人の**減額**もできる <span class="src">出典：[App Store](https://apps.apple.com/jp/app/groupay/id1387267486)</span>
- 機能はすべて無料で、広告は ¥100 で消せる <span class="src">出典：[App Store](https://apps.apple.com/jp/app/groupay/id1387267486)</span>
- 精算結果を LINE やメールで送れる <span class="src">出典：[App Store](https://apps.apple.com/jp/app/groupay/id1387267486)（レビューへの開発者の回答）</span>
- イベントごとに通貨の単位を変えられる <span class="src">出典：[アプリブ](https://app-liv.jp/lifestyle/all/1044/)</span>

**気になる点**

- **共同編集はできない**。旅行のように全員が立て替える場面には向かない <span class="src">出典：[アプリブ](https://app-liv.jp/lifestyle/all/1044/)</span>
- 均等に割るためのアプリで、一人ずつの金額を直接入れる形ではない <span class="src">出典：[App Store](https://apps.apple.com/jp/app/groupay/id1387267486)（レビューへの開発者の回答）</span>
- 金額や人数によっては数円の誤差が出ることがある <span class="src">出典：[App Store](https://apps.apple.com/jp/app/groupay/id1387267486)</span>

### レコペイ

メンバー全員で立て替えを記録する、共同編集型の割り勘アプリです（iOS・Android）。<span class="src">出典：[レコペイ公式](https://reco-pay.com/)</span>

**良い点**

- アプリを入れた全員が同じデータを見て記録できる（共同編集）。アプリを入れている一人が、ほかの人の分をまとめて記録してもいい <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>
- **50以上の通貨**に対応し、支払いごとに通貨を選べる。精算は円に換算しても、現地通貨のままでもできる <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>
- 送金の回数が少なくなるように精算し、計算のしかたを FAQ で説明している <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>
- AI のレシート読み取り、「今誰が多く払っているか」の分析 <span class="src">出典：[レコペイ公式](https://reco-pay.com/)</span>

**気になる点**

- **無料版では、イベントを1つずつしか進められない**。進行中のイベントは1つまでで、前のイベントを「完了」にするまで次を作れない。旅行の精算が終わらないうちに次の飲み会が来る、同居の生活費と旅行を分けて記録したい、といった使い方では足りなくなる <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>
- 複数のイベントを並べて管理するなら、有料の PLUS（月額 ¥500・年額 ¥3,600）を考えることになる。有料版では上限がなくなるとされている <span class="src">出典：[App Store](https://apps.apple.com/jp/app/id1669984018)・[アプリブ（2023年）](https://app-liv.jp/5348577/)</span>
- 記録する人はアプリを入れる必要がある <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>
- 機種変更の引き継ぎは、LINE 公式アカウントへの問い合わせで行う <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>
- 広告がページの下に少し出る <span class="src">出典：[レコペイ公式 FAQ](https://reco-pay.com/)</span>

## 送金は、PayPay などで

割り勘アプリが出してくれるのは「**誰が誰にいくら**」までです。実際のお金のやりとりは、PayPay などの送金サービスか現金で行います。

割り勘アプリが活きるのは、**立て替えが何件も混ざるとき**です。
4人で旅行して、宿・レンタカー・ガソリン・夕食をそれぞれ別の人が払うと、手で計算するのはかなり大変です。
このあたりの計算の考え方は、[割り勘の端数、どう処理するのが揉めないか](/archives/225/)で詳しく書いています。

## よくある質問

### 登録なしで使える割り勘アプリは？

幹事も参加者も、登録もインストールもなしで記録まで使えるのは **wa/ri**・**Walica**・**タテカリ**です。
wa/ri はブラウザ版だけで全部できるうえ、同じルームにアプリや LINE からも入れます。続けて使うなら、記録の通知・レシート読み取り・CSV／PDF の書き出し・ホーム画面のウィジェットが使えるアプリが便利です。機種を変えても記録を引き継ぎたいときだけアカウントを作ります。

### 完全に無料で、制限がないものは？

**wa/ri**・**Walica**・**タテカリ**・**groupay** は、機能の制限なく無料で使えます（4つとも広告あり）。
**Splitwise**（支出の追加は1日4件まで）と **レコペイ**（進行中のイベントは1つまで）は、無料版に制限があります。

### 飲んだ人だけで割りたい

6つとも、支払いごとに**対象の人を選べます**。
1回の会計のなかで「お酒は飲んだ人だけ、料理は全員」のように分けたいなら、明細ごとに対象を選べる **wa/ri** が手間が少ないです。

### 上司は多め、のように割合を決めたい

**Splitwise**（割合・シェア）か **タテカリ**（金額を直接指定）が向いています。

## まとめ

- **飲み会**：品目ごとに分けるなら wa/ri（無料）か Splitwise（Pro）、一部の人だけ減額するなら groupay
- **国内旅行**：みんなでリンクから記録するなら wa/ri・Walica・タテカリ。計算の中身を見せて揉めずに精算したい、編集できる人を分けたいなら wa/ri
- **海外旅行**：外貨の換算まで任せるならタテカリ（無料）か Splitwise（Pro）
- **同居・カップル**：長く続けるなら Splitwise・レコペイ・wa/ri

どれを選んでも、いちばん効くのは**先に決め方を共有しておくこと**です。
「今回はこのアプリで、割り方はこう」と最初に言っておけば、精算の場で止まらずに済みます。
