宿は予約した人がまとめて払う。レンタカーは別の人。ガソリンと高速代はまた別の人。
年末年始の旅行は、**立て替えがいちばん混ざる**場面です。

そこに「1日遅れて合流する人」や「お酒を飲まない人」がいると、
単純に人数で割るわけにもいかなくなります。

先に、出発前に決めておくことを置きます。計算はそのあとです。

### 出発前に決めておくこと

| 決めること | よくある決め方 |
|---|---|
| **何を割るか** | 宿・交通・全員での食事は割る。おみやげや個人の買い物は入れない |
| **途中から合流・途中で帰る人** | 参加した日の分だけ負担する |
| **誰が何を立て替えるか** | 宿は予約した人、レンタカーは借りた人、と担当を分けておく |
| **お酒の扱い** | 飲み代を別の支払いに分けて、飲んだ人だけで割る |
| **いつ精算するか** | 帰ってから3日以内。日が空くほど言い出しにくくなる |

ここが決まっていれば、計算は足し算と引き算だけです。

### 例：1日遅れて合流する人がいる2泊3日

A・B・C の3人で出発して、D は2日目から合流。立て替えはこの6件です。

| 何 | 払った人 | 金額 | 割る人 | 一人あたり |
|---|---|---:|---|---:|
| 宿（1泊目） | A | 30,000円 | A・B・C | 10,000円 |
| 宿（2泊目） | A | 40,000円 | 4人 | 10,000円 |
| レンタカー（3日間） | B | 21,000円 | 4人 | 5,250円 |
| ガソリン・高速代 | C | 8,000円 | 4人 | 2,000円 |
| 1日目の夕食 | C | 9,000円 | A・B・C | 3,000円 |
| 2日目の夕食 | D | 16,000円 | 4人 | 4,000円 |
| **合計** | | **124,000円** | | |

まず、一人ずつの**負担する額**を出します。

| 人 | 宿 | レンタカー | ガソリン・高速 | 夕食 | 負担する額 |
|---|---:|---:|---:|---:|---:|
| A | 20,000 | 5,250 | 2,000 | 7,000 | **34,250円** |
| B | 20,000 | 5,250 | 2,000 | 7,000 | **34,250円** |
| C | 20,000 | 5,250 | 2,000 | 7,000 | **34,250円** |
| D | 10,000 | 5,250 | 2,000 | 4,000 | **21,250円** |
| **合計** | | | | | **124,000円** |

次に、一人ずつ「**立て替えた額 − 負担する額**」を出します。

| 人 | 立て替えた額 | 負担する額 | 差 |
|---|---:|---:|---:|
| A | 70,000円 | 34,250円 | **+35,750円**（受け取る） |
| B | 21,000円 | 34,250円 | **−13,250円**（払う） |
| C | 17,000円 | 34,250円 | **−17,250円**（払う） |
| D | 16,000円 | 21,250円 | **−5,250円**（払う） |
| **合計** | | | **0円** |

**差の合計は必ず 0 になります。** ならないときは、どこかで計算を間違えています。

受け取るのは A だけなので、精算はこの3回で終わりです。

| 送金 | 金額 |
|---|---:|
| B → A | 13,250円 |
| C → A | 17,250円 |
| D → A | 5,250円 |

#### 全部を4人で割っていたら

124,000円 ÷ 4人 = 一人 31,000円。
D は**来ていない1泊目の宿と夕食の分まで、9,750円多く**払うことになります。
「参加した人だけで割る」を守るだけで、この差が出ません。

### 帰省の相乗り：ガソリン代と高速代

車で帰省するときに、同じ方面の人を乗せていく。
このときの割り勘は、**ガソリン代・高速代・駐車場代**を乗った人で分けるのが基本です。

ガソリン代は、**走った距離 ÷ 燃費 × 1Lあたりの値段**で出せます。

| | 例 |
|---|---:|
| 走った距離（往復） | 600km |
| 燃費 | 15km/L |
| 使ったガソリン | 40L |
| 1Lあたりの値段 | 170円 |
| **ガソリン代** | **6,800円** |
| 高速代（往復、ETC の利用明細の金額） | 12,000円 |
| **合計** | **18,800円** |

数字はすべて例です。給油したレシートがあれば、そちらの金額を使うのがいちばん確かです。

これを何人で割るかは、乗る人どうしで先に決めておきます。

| 決め方 | 4人で乗った場合 | 向いている場面 |
|---|---:|---|
| 運転する人も含めて全員で割る | 一人 4,700円 | 運転を交代するとき |
| 運転する人以外で割る | 一人 約6,267円（3人） | 運転を1人に任せるとき |
| 全員で割って、車の持ち主に少し上乗せして渡す | 一人 4,700円＋α | 車の持ち主の車で行くとき |

どれが正しいということはありません。**出発前に1つに決めておく**ことだけが大事です。

### 海外旅行：円と現地通貨が混ざるとき

海外旅行では、航空券や空港までの交通は**円**で、現地の食事やタクシーは**現地通貨**で払います。
これを1つにまとめて精算するには、やり方が2つあります。

| やり方 | 手順 | 気をつけること |
|---|---|---|
| **全部を円に直してから割る** | カードで払った分は利用明細に載る円の金額、現金で払った分は両替したときのレートで円にする | カードの円の金額は、明細が出るまで決まらない。海外利用の手数料が含まれていることも多い |
| **通貨ごとに別々に精算する** | 円で払った分は円で、現地通貨で払った分は現地通貨で精算する | 現地通貨の精算は、**現地にいるあいだに現金で**済ませるのが早い |

**通貨ごとに分けるほうが、計算は簡単です。**
レートの話が出てこないので、帰国してから明細を待つ必要もありません。

円に直してまとめたいときは、**誰のレートを使うか**を先に決めておきます。
両替した場所やカードの会社によってレートが違うので、ここが決まっていないと金額が人によって変わります。

### アプリでやるなら

割り勘アプリ [wa/ri](/apps/wa-ri/) は、この記事の計算をそのままやります。

- 支払いを記録するときに、**払った人と、割る人**を選べる。途中から合流した人は、合流してからの支払いにだけ入れればいい
- 誰が誰にいくら払えば終わるかを、**計算過程まで**表示する
- ルームに旅行の日程（[イベント日](/guide/wa-ri/#20-イベント日とライブアクティビティ)）を決めておくと、一覧に「あと◯日」「進行中」と出る
- 招待リンクを送っておけば、**立て替えた人が自分で記録**できる（オーナーが「メンバーの編集を許可」を ON にしたとき）。参加する人はアプリもアカウントも要りません
- 電波の入らない場所では、金額だけ先に「**一時記録**」に控えておける（[一時記録](/guide/wa-ri/#13-あとで登録する一時記録)）
- 精算のあとは「**集金**」で、誰が払い終えたかを残せる

外貨については、できることとできないことがあります。

- ルームを作るときに、**円・米ドル・ユーロ・英ポンド・韓国ウォン・人民元・台湾ドル・香港ドル・タイバーツ・豪ドル**の10通貨から1つ選べる（[外貨ルーム](/guide/wa-ri/#17-海外旅行で使う外貨ルーム)）
- **通貨は1ルームに1つで、円への自動換算はしない**
- なので、上の「通貨ごとに別々に精算する」なら、**円のルームと現地通貨のルームを分けて**作るのが合っています。「全部を円に直してから割る」なら、円に直した金額を円のルームに入れます

---

旅行の精算で揉めるのは、金額が大きいからではありません。
**何を誰で割るかを、出発前に決めていないから**です。表の5行を先に決めておけば、帰ってからの精算は数分で終わります。
