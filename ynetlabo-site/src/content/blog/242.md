2027年の成人の日は **1月11日（月）** です。
親戚や知人の子が成人を迎えるとき、いくら包むか、いつ渡すか、お返しは要るか。

先に、関係ごとの目安を置きます。

### 関係ごとの目安

よくいわれる目安です。家ごとの習慣で大きく変わります。

| 関係 | 目安 |
|---|---|
| 祖父母から孫へ | 10,000〜100,000円（幅が広い）|
| おじ・おばから | 10,000〜30,000円 |
| いとこ・親戚の子 | 5,000〜10,000円 |
| 友人・知人の子 | 5,000〜10,000円 |
| 職場の部下・後輩 | 3,000〜5,000円、または品物 |

品物で贈るなら、**大人になってから長く使えるもの**が選ばれます。腕時計、名刺入れ、印鑑、万年筆、お財布など。
本人が欲しいものを親に聞いてから選ぶと外しません。

### 18歳と20歳、どちらで渡す？

2022年4月から成人年齢は18歳になりましたが、**式典（「二十歳のつどい」など）は20歳で行う自治体が多い**ままです。
そのため「どちらで渡すか」が家によって分かれています。

| 渡す時期 | 向いている考え方 |
|---|---|
| **20歳の式典のころ** | 式典に合わせて祝う。いまも一番多い |
| **18歳の誕生日** | 法律上の成人を祝う |
| **高校卒業のころ（18歳）** | 卒業・進学祝いとまとめて渡す |

大事なのは、**両方で渡して二重にならないようにすること**と、**きょうだいや親戚の間で時期をそろえること**です。
上の子には20歳で渡したのに、下の子は18歳で渡した、となると後で気になります。

### のしと渡す時期

| | 目安 |
|---|---|
| 水引 | **紅白の蝶結び**（何度あってもよいお祝い）|
| 表書き | 「**御成人御祝**」「**祝御成人**」「**御祝**」 |
| 名前 | 水引の下に、贈る側の名前をフルネームで |
| 渡す時期 | 成人の日（式典）の前後、または誕生日。**当日までに届く**ようにすると喜ばれる |

### いただいた側のお返し

成人祝いへのお返しは、**基本的に要りません。** 祝ってもらう本人には、まだ収入がないことが多いからです。
そのかわり、次のことはしておきます。

- **本人からお礼を伝える。** 電話や手紙で、自分の言葉で。成人した最初の「大人としてのあいさつ」になります
- **式典の写真を添える。** 振袖やスーツの写真は、祖父母や親戚にとって何よりのお返しです

それでも何か返したいときは、**内祝い**として贈ります。

| | 目安 |
|---|---|
| 金額 | いただいた額の**3分の1〜半分** |
| 時期 | 式典や誕生日から1ヶ月以内 |
| 表書き | 「内祝」、名入れは**本人の名前** |
| 品物 | お菓子やタオルなど、相手の負担にならないもの |

金額の目安は[お返し計算機](/tools/okaeshi/)でも出せます（名目は「そのほか」を選びます）。

### 誰から何をいただいたかを、残しておく

成人祝いは、祖父母・おじおば・親の友人と、**一度にまとまっていただく**お祝いです。
そして何年かすると、こんどはこちらが**相手の子の成人や結婚を祝う番**が来ます。
そのときに「あのとき、いくらいただいたか」が分からないと困ります。

慶弔記録アプリ [tsutsum](/apps/tsutsum/) には「成人祝い」という名目はありませんが、
**慶事 → その他のお祝い**で記録できます。

- いただいたお祝いは「**もらった**」で記録すると、**お返しの目安（3分の1〜半分）**が出ます。お返しをしないときは「今回なし」で閉じておけます（[お返しを管理する](/guide/tsutsum/#returns)）
- 何人分もまとめて記録するときは、保存のあとの「**同じイベントにもう1件**」で、相手と金額だけを続けて入れられます（[はじめての記録](/guide/tsutsum/#record-new)）
- 相手ごとに、いただいたもの・贈ったものと収支が並びます

記録は端末の中だけに保存され、サーバーには送られません。
