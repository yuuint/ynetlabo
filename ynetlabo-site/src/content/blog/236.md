忘年会の幹事を頼まれた。何から手をつければいいか。

やることは多く見えますが、**時期ごとに分けると、1回あたりは数分で終わる作業**ばかりです。
困るのはたいてい作業の量ではなく、**決めておくべきことを決めないまま当日を迎えること**のほうです。

先にチェックリストを置きます。解説はそのあとです。

### チェックリスト

| いつ | やること | ここで決めておくこと |
|---|---|---|
| **2週間前まで** | 日程を決める・お店を予約する・案内を送る | 人数の目安、コースと飲み放題の有無、**会費**、キャンセルの期限 |
| **1週間前** | 出欠を締める・お店に人数を伝える | **会費の集め方**（前払いか当日か）、二次会をやるかどうか |
| **前日** | リマインドを送る・人数の変更をお店に伝える | 釣り銭の用意、送金先の案内 |
| **当日** | 受付で会費を集める・会計をする | 領収書の宛名、二次会の場所 |
| **翌日〜3日以内** | 立て替えた人に返す・お礼を送る | 余った会費・足りなかった分の扱い |

「決めておくこと」の列が大事です。
ここが空いたまま当日になると、**会計の場で全員が止まります。**

### 2週間前まで：日程・お店・会費

#### 日程

12月の金曜・土曜は、どのお店も早く埋まります。
候補日を2〜3日出して、**多数決ではなく「この日なら来られない人がいない」日**を選ぶと、あとの調整が減ります。

#### お店の予約

予約のときに確認しておくのはこの4つです。

| 確認すること | なぜ |
|---|---|
| コースの料金と、飲み放題の時間 | 会費の計算の元になる |
| 人数が増減したときの期限 | 前日に1人減ったとき、その分を払うかどうかが決まる |
| キャンセル料がかかる日 | 雪や体調不良で中止になったときの判断材料 |
| 支払い方法（カード・QR決済） | 幹事がまとめて払えるかどうか |

#### 会費の決め方

会費は**お店に払う額から逆算**して、**500円単位に切り上げる**のが扱いやすいです。

12人、コース 5,000円（飲み放題込み）の例で計算します。

| | 金額 |
|---|---|
| コース代 5,000円 × 12人 | 60,000円 |
| 追加注文の見込み | 3,000円 |
| 合計 | 63,000円 |
| 一人あたり（63,000円 ÷ 12人）| 5,250円 |
| **会費（500円単位に切り上げ）** | **5,500円** |

5,500円 × 12人 = 66,000円。追加注文が見込みどおりなら、**3,000円余ります。**

この余りをどうするかを、**案内を送る時点で書いておきます。**

- 二次会の費用に回す
- 当日、全員に返す
- 次の集まりに繰り越す

どれでも構いません。先に書いておけば、あとで誰も気にしません。
端数の考え方は[割り勘の端数、どう処理するのが揉めないか](/archives/225/)にまとめています。

#### 差をつけるかどうか

| 場面 | よくあるやり方 |
|---|---|
| 上司・先輩が多めに出す | 役職で 1,000〜2,000円ずつ上乗せ、または「上司から◯円いただきました」と総額から引く |
| お酒を飲まない人がいる | 飲み放題を付けないコースにする、または一律で 1,000円引く |
| 遅れて来る・早く帰る人がいる | 一律で扱う（調整すると計算が合わなくなりやすい） |

差をつけるなら、**案内の段階で金額まで書いておく**こと。
当日に「やっぱり飲まなかったので」と言われてから計算し直すのが、いちばん大変です。

### 1週間前：出欠を締める・会費の集め方

#### 会費の集め方は3通り

| 集め方 | 良いところ | 気をつけること |
|---|---|---|
| **前払い（送金）** | 当日の受付が要らない。ドタキャンの分を取りこぼさない | 支払った人を幹事が確認する手間がある |
| **当日・現金** | 準備が要らない。いちばん伝わりやすい | 釣り銭が要る。会計の前に集め終わる必要がある |
| **後払い（翌日に送金）** | 当日の手間がない | 払い忘れが出る。幹事の立て替え額が一番大きくなる |

職場の忘年会なら**当日・現金**、友人同士なら**前払い**が多い印象です。
どちらにしても、**集め方を案内に1行書いておく**だけで、当日の受付が早くなります。

### 前日：リマインドと釣り銭

当日・現金で集めるなら、**釣り銭を前日に用意しておきます。**

会費 5,500円で、全員が 1万円札を出してきた場合、お釣りは 1人 4,500円。
12人全員なら 54,000円ぶんの千円札と500円玉が要ります。現実的ではありません。

だから案内に**「なるべくちょうどでお願いします」**と1行入れておき、
そのうえで**千円札 10枚・500円玉 5枚くらい**を持っていけば、たいてい足ります。

リマインドには、日時・お店の名前と地図・会費・集め方を、**もう一度まとめて**送ります。
最初の案内を探してもらうより、そのほうが早いです。

### 当日：受付と会計

- **乾杯の前に会費を集め終える。** 飲み始めると集めにくくなります
- 集めた人には、名簿にその場で印を付ける
- 会計では**領収書をもらう**。宛名は会社名か「上様」か、事前に決めておく
- 追加注文で会費を超えたときは、**その場で全員から集めない**。いったん幹事が払って、翌日に精算するほうが場が止まりません

### 二次会とタクシーで、立て替えが混ざる

一次会を会費制できれいに締めても、**二次会からは立て替えが始まります。**

- 二次会のお店で、誰かがカードでまとめて払う
- タクシーを2台に分けて、それぞれ別の人が払う
- 帰りにコンビニで誰かが買い出しをする

払った人がばらばらになるので、**誰が何をいくら払ったかを、その場で残しておく**ことが大切です。
翌日に記憶で再現しようとすると、ほぼ確実に合いません。

### 翌日〜3日以内：精算とお礼

精算は**記憶が新しいうちに**終わらせるのが一番です。日が空くほど言い出しにくくなります。

1. 一次会の余り・不足をはっきりさせる
2. 二次会以降の立て替えを合計して、**誰が誰にいくら払えば終わるか**を出す
3. グループに結果を送る
4. 払い終わった人に印を付けていく

最後に、来てくれた人と、店選びや受付を手伝ってくれた人に一言お礼を送れば、幹事の仕事は終わりです。

### 二次会からの立て替えを、アプリでまとめるなら

割り勘アプリ [wa/ri](/apps/wa-ri/) は、二次会以降の立て替えの記録と精算に使えます。

- **先にルームを作っておく。** 会の日付（[イベント日](/guide/wa-ri/#20-イベント日とライブアクティビティ)）を決めておくと、一覧で「あと◯日」と出ます
- **招待リンクを LINE で送るだけ。** 参加する人はアプリもアカウントも要りません。その場にいる人には QR コードを読み取ってもらうこともできます（[メンバーを招待する](/guide/wa-ri/#10-メンバーを招待する)）
- ルームの設定で「**メンバーの編集を許可**」を ON にすると、**払った人が自分で記録**できます。幹事が全部打ち込まなくて済みます
- 誰が誰にいくら払えば終わるかを、**計算過程まで**表示します
- 1回のお会計を**品目ごとに分けて、食べた人だけで割る**こともできます（[明細ごとに分ける](/guide/wa-ri/#15-1回のお会計を明細ごとに分ける)）
- レシートをカメラで読み取れます（iOS 版・Android 版）
- 精算のあとは「**集金**」で、誰が払い終えたかを残せます（[集金を記録して精算を追う](/guide/wa-ri/#16-集金を記録して精算を追う)）
- 金額が出そろったら「**確定**」にしておくと、あとから記録が変わらず、全員が同じ結果を見られます

---

幹事の仕事は、結局のところ**先に決めて、先に書いておくこと**です。
会費、余りの扱い、集め方。案内に3行書いておくだけで、当日の会計は止まりません。
