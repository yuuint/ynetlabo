## v2.03 の更新内容

### 1.カテゴリを5つ追加しました

記録のカテゴリに、次の5つを追加しました。

| カテゴリ | 使い方の目安 |
| --- | --- |
| 買い物 | 現地での買い物、コンビニ、日用品など |
| 飛行機 | 航空券、座席指定、手荷物料金など |
| 鉄道 | 新幹線、特急、ICカードのチャージなど |
| チケット | 入場券、ライブ、テーマパークなど |
| お土産 | みんなで買ったお土産、差し入れなど |

これまで「交通」にまとめていた移動費を、飛行機・鉄道と分けて記録できるようになりました。
旅行のあとで「何にいくら使ったか」を振り返りやすくなります。

カテゴリは以下の順で表示されます。

飲食 → 買い物 → 交通 → 飛行機 → 鉄道 → 宿泊 → アクティビティ → チケット → お土産 → その他 → 未設定

### 2.「集金」の記録に対応しました

旅行中に誰かが誰かへ現金を渡した、送金アプリで先に精算した ——
そんなメンバー間のお金のやり取りを記録できるようになりました。

記録画面の右上に「支払 / 集金」の切り替えを追加しています。
「集金」に切り替えると、受け取った人と渡した人をそれぞれ1人ずつ選ぶ形に変わります。

集金は立て替えとは違い、割り勘して負担を分けるものではありません。
そのため支出の一覧やグラフには含めず、専用の「集金」タブでまとめて確認できるようにしました。
記録した集金は、割り勘結果に自動で反映されます。

### 3.招待リンクがアプリで直接開くようになりました

共有した招待リンクをタップしたとき、アプリがインストールされていれば
ブラウザを経由せずそのままアプリが開くようになりました。
ルームへの参加がスムーズになります。

### 4.カテゴリの表示を見直しました

- 並び順が固定になり、どの画面でも同じ順序で表示されるようになりました
- カテゴリ名が省略されず表示されるようになりました（これまでは3文字まで）
- 英語表示時の名称を分かりやすくしました（Trn → Transport など）
- オフラインのときもカテゴリが表示されるようになりました

### 5.設定に「規約・アカウント」を追加しました

設定画面から、プライバシーポリシー・利用規約・Y.NetLaboアカウントの説明を
確認できるようになりました。

### 6.不具合を修正しました

- カテゴリの読み込みに失敗すると、記録画面が「読み込み中」のまま進まないことがある問題
- オフラインの一時記録で、本来選べないはずのカテゴリが候補に出ていた問題
- カテゴリのアイコンが画面によって違って見えることがある問題

## v2.04 の更新内容

iOS 版・Android 版・Web 版のいずれも v2.04 で対応しています。

### 7.ルームの権限を整理しました

ルームを作った人（オーナー）と、招待されて参加した人（参加者）で
できる操作をはっきり分けました。

| 操作 | オーナー | 参加者 |
| --- | --- | --- |
| 記録の追加・編集・削除 | ○ | 「メンバーの記録編集を許可」がオンのとき ○ |
| 記録・割り勘結果の閲覧 | ○ | ○ |
| ルーム設定の変更 | ○ | × |
| メンバーの追加・変更・削除 | ○ | × |
| メンバー一覧の閲覧 | ○ | ○ |
| 招待リンクの作成 | ○ | × |
| 作成済み招待リンクの共有 | ○ | ○ |
| ルームを削除する | ○ | × |
| ルームから抜ける | — | ○ |

ご自身が使えない操作は、鍵のマークと「ルームオーナーのみ操作できます」のご案内を添えて
うすい表示になります。どこまで操作できるのかが、画面を見ただけで分かるようになりました。

招待リンクがまだ作られていないルームでは、参加者の方に
「ルームオーナーに作成を依頼してください」とご案内します。

Android 版・Web 版では、ルーム画面の表示が「管理者 / 参加者」になり、
そのルームでの自分の立場がひと目で分かるようになりました。

### 8.「一時記録から復元」をボタンにまとめました（iOS）

記録画面の一番上に一時記録が一覧で並んでいたのを、
「内容は？」の横にある「一時記録から復元」ボタンから選ぶ形に変更しました。
一時記録がたまっていても、記録画面がすっきりしたままになります。

### 9.カテゴリのアイコン表示を改善しました（Android / Web）

カテゴリのアイコンが、iOS 版・Android 版・Web 版で同じ見た目に揃いました。
これまで一部のカテゴリで表示が違って見えることがありましたが、
どの端末でも本来のアイコンで表示されます。
今後カテゴリが増えたときも、すぐに新しいアイコンで表示されます。

### 10.下部タブのラベルを常に表示するようにしました（Android / Web）

これまでは選択中のタブしかラベルが出ず、ほかのタブが何なのか分かりにくい状態でした。
すべてのタブでラベルを表示するようにしています。

### 11.広告トラッキングの事前説明を追加しました（iOS）

トラッキング許可の確認画面（iOS 標準）の前に、なぜ確認するのかをご説明する画面を
表示するようにしました。

wa/ri は広告収入によって無料でお使いいただけるようにしており、
トラッキングはお客様に合った広告を表示するために利用します。
許可する / しないは、これまでどおり iOS 標準の画面でお選びいただけます。

### 12.不具合を修正しました

- アカウント登録のご案内が、トラッキングの確認画面と重なって表示されることがある問題（iOS）
