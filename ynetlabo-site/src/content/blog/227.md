9月の更新内容をまとめます。
**v2.06 は公開済み**、**v2.07 は審査に提出済み**で、通り次第の公開となります。

## v2.06 の更新内容（公開済み）

### 1. 1回のお会計を明細ごとに分けられるようになりました

飲み会やコンビニでの買い物のように、**1回の会計に「誰の分か」が混ざっている**ときのための機能です。
会計をまとめたまま、品目ごとに割り勘の対象を変えられます。

記録の一覧では会計ごとのまとまりで並び、「まとめて編集」から日付・立替者・会計メモ・明細を
ひとつの画面で直せます。iOS / Android / Web のすべてでご利用いただけます。

### 2. レシートを撮ると、明細がそのまま入ります

**レシートを1枚撮れば、明細・日付・店名をまとめて取り込めます**（iOS / Android）。
値引きは直前の明細から引き、外税は税率ごとに対象の明細へ配るので、
取り込んだ明細の合計はレシートの合計と合います。

撮影も文字の読み取りも端末の中で完結します。レシートの画像はどこにも送信しません。

画面図つきの詳しい説明は、[v2.06 の予告記事](/archives/226/)にまとめています。

## v2.07 の更新内容（審査提出済み）

### 3. 記録を1枚のレポートとしてPDFに残せます

PDFの出力を作り直しました。これまでは記録を縦に並べただけでしたが、
**3つの章にまとめたレポート**になります。用紙はA4横です。

| 章 | 内容 |
| --- | --- |
| 1. 合計金額 / カテゴリ別サマリー | 立替額と集金額の合計。カテゴリごとの立替金額を円グラフと表で並べます |
| 2. 割り勘方法の提示 | 「まとめすぎない方法」と「全てまとめた方法」の2通りで、誰が誰にいくら払うかを出します。立替・集金・相殺の計算過程も付きます |
| 3. 記録詳細一覧 | 立替の記録と集金の記録を、それぞれ表にして全件並べます |

紙面の上にはルームのアイコンと名前、下にはページ番号が入ります。
そのまま印刷して旅のしおりに綴じたり、精算の控えとして配ったりできます。

明細に分けて登録した会計は、3章でも**会計ごとのまとまり**で並びます。
これまで出力に含まれていなかった**集金の記録**も、立替とは別の表で載るようになりました。

### 4. CSV／PDF の出力から広告をなくしました

これまで出力の前に広告の視聴確認を出していましたが、**やめました。**
確認なしで、そのまま出力できます。

### 5. CSVを扱いやすくしました

- Excel で開いても**文字化けしません**
- 保存されるファイルに **`.csv` / `.pdf` の拡張子**が付くようになりました
- 外貨のルームのために、金額を**通貨の小数どおり**に書いた列（`10.50` のような形）を足しました

これまでの列はそのまま残してあるので、すでに取り込みの仕組みをお持ちの方も影響を受けません。

### 6. チュートリアルにページが増えます

レシートの読み取りとPDFレポートの紹介ページを足しました。
アップデート後の初回起動で、**増えたページだけ**が「アップデート情報」として出ます。
設定 → チュートリアルからは、いつでも最初から見直せます。

## ご利用にあたって

- **PDFレポートと広告の廃止は iOS 版・Android 版が先行します。** Web 版は従来どおりの出力のままです。
- CSV の出力では、明細は1件ずつの行として並びます。PDF では会計ごとのまとまりで並びます。
- 記録が0件のときは「出力できる記録がありません」で止まります。
- 出力はルームオーナーでなくても実行できます。
- PDFの2章（割り勘方法）はオンラインでの出力が必要です。通信できないときは、その旨だけが入ります。
