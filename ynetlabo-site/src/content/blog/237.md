一次会は会費制で、きれいに締まった。
問題はそのあとです。

- 二次会のカラオケで、誰かがカードでまとめて払う
- 締めのラーメンには、4人だけ行く
- 帰りのタクシーは2台に分かれて、それぞれ別の人が払う

**払った人も、参加した人も、場面ごとに違う。**
翌日「で、結局いくら払えばいいの？」となるのは、たいていこの形です。

先に結論を書きます。

> 1. **場面ごとに、参加した人だけで割る**
> 2. 一人ずつ「**立て替えた額 − 負担する額**」を出す
> 3. **マイナスの人が、プラスの人に払う。** 送金はまとめてから

順番に、実際の数字で計算します。

### 例：6人の二次会から

二次会に行ったのは A・B・C・D・E・F の6人。そのあとの立て替えはこの4件です。

| 場面 | 払った人 | 金額 | 参加した人 | 一人あたり |
|---|---|---:|---|---:|
| 二次会（カラオケ） | B | 18,000円 | 6人全員 | 3,000円 |
| 締めのラーメン | C | 4,800円 | A・B・C・D | 1,200円 |
| タクシー1台目 | E | 3,600円 | A・C・E | 1,200円 |
| タクシー2台目 | F | 3,000円 | B・D・F | 1,000円 |
| **合計** | | **29,400円** | | |

ポイントは「参加した人」の列です。
**全部を6人で割ってしまうと、ラーメンに行っていない E と F が、食べていない分まで払うことになります。**

### 一人ずつの「負担する額」を出す

場面ごとの一人あたりを、参加した人に足していきます。

| 人 | 二次会 | ラーメン | タクシー | 負担する額 |
|---|---:|---:|---:|---:|
| A | 3,000 | 1,200 | 1,200 | **5,400円** |
| B | 3,000 | 1,200 | 1,000 | **5,200円** |
| C | 3,000 | 1,200 | 1,200 | **5,400円** |
| D | 3,000 | 1,200 | 1,000 | **5,200円** |
| E | 3,000 | — | 1,200 | **4,200円** |
| F | 3,000 | — | 1,000 | **4,000円** |
| **合計** | | | | **29,400円** |

負担する額の合計が、払われた合計（29,400円）と一致すれば正しく割れています。

### 「立て替えた額 − 負担する額」を出す

| 人 | 立て替えた額 | 負担する額 | 差 |
|---|---:|---:|---:|
| A | 0円 | 5,400円 | **−5,400円**（払う） |
| B | 18,000円 | 5,200円 | **+12,800円**（受け取る） |
| C | 4,800円 | 5,400円 | **−600円**（払う） |
| D | 0円 | 5,200円 | **−5,200円**（払う） |
| E | 3,600円 | 4,200円 | **−600円**（払う） |
| F | 3,000円 | 4,000円 | **−1,000円**（払う） |
| **合計** | | | **0円** |

**差の合計は必ず 0 になります。** ならないときは、どこかで計算を間違えています。

C・E・F は自分でも立て替えていますが、差し引きするとまだ少し払う側です。
受け取るのは B だけなので、**全員が B に払えば終わり**です。

| 送金 | 金額 |
|---|---:|
| A → B | 5,400円 |
| C → B | 600円 |
| D → B | 5,200円 |
| E → B | 600円 |
| F → B | 1,000円 |

**5回**で終わりました。

### まとめないと、12回になる

同じ4件を、**レシートごとに精算**するとどうなるか。

| 場面 | 送金 | 回数 |
|---|---|---:|
| 二次会 | A・C・D・E・F → B（3,000円ずつ） | 5回 |
| ラーメン | A・B・D → C（1,200円ずつ） | 3回 |
| タクシー1台目 | A・C → E（1,200円ずつ） | 2回 |
| タクシー2台目 | B・D → F（1,000円ずつ） | 2回 |
| **合計** | | **12回** |

12回の送金のうち、C は B に 3,000円払いながら B から 1,200円もらっていて、行って帰ってきているだけのお金があります。
**差し引きしてからまとめると、送金の回数は「人数 − 1」回以下に収まります。** この例なら 6人で5回です。

受け取る人が複数いるときは、**一番多く払う人から、一番多く受け取る人へ**順に組み合わせます。
くわしい手順は[割り勘の端数、どう処理するのが揉めないか](/archives/225/)にまとめています。

### まとめないほうがいいとき

まとめると回数は減りますが、**「誰に払うのか」が実際の支払いとずれる**ことがあります。
上の例でも、ラーメン代を立て替えたのは C なのに、A は C ではなく B に払っています。

- 仲の良い6人なら、まとめて回数を減らすほうが楽
- 「自分が立て替えた分は、本人から直接返してほしい」人がいるなら、まとめないほうが納得されやすい

どちらでもいいので、**どちらで精算するかを先に1つに決めて、全員に同じ結果を見せる**ことが大切です。
人によって違う計算で送金すると、合計が合わなくなります。

### 二次会で立て替えた人が、その場でやっておくこと

翌日に記憶で再現すると、ほぼ確実に合いません。その場でやっておくのは2つだけです。

- **レシートを撮っておく**（金額と店名が残る）
- **誰が参加したかを、その場で1行メモしておく**（「ラーメン：A・B・C・D」）

特に2つめ。金額はレシートに残りますが、**誰がいたかはどこにも残りません。**

### アプリでやるなら

割り勘アプリ [wa/ri](/apps/wa-ri/) は、この記事の計算をそのままやります。

- 支払いを記録するときに、**払った人と、割る人（参加した人）**を選べる
- 誰が誰にいくら払えば終わるかを、**計算過程まで**表示する
- 「**まとめる**」を ON にすると、支払いを束ねて送金の回数を減らす。OFF なら支払いのつながりを残す
- ルームのオーナーが割り方を選んで「**確定**」すると、全員がその割り方の同じ結果を見る（[割り勘結果を見る](/guide/wa-ri/#9-割り勘結果を見る)）
- 招待リンクを送っておけば、**立て替えた人が自分で記録**できる（オーナーが「メンバーの編集を許可」を ON にしたとき）。参加する人はアプリもアカウントも要りません
- レシートをカメラで読み取れる（iOS 版・Android 版）

---

二次会の精算で揉めるのは、計算が難しいからではありません。
**誰がどこにいたかが残っていないから**です。その場で1行残しておけば、あとは足し算と引き算で終わります。
