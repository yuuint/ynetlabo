急な訃報のとき、コンビニで香典袋を手に取って固まることがある。
「御霊前」と「御仏前」が並んでいて、どちらを選べばいいのか分からない。

結論から書くと、**通夜・葬儀は「御霊前」、四十九日以降の法要は「御仏前」が基本**です。
ただし浄土真宗だけは例外で、通夜・葬儀から「御仏前」を使います。

以下、迷いやすいところを順にまとめます。金額の目安は
[ご祝儀・香典の相場早見表](/tools/souba)にあります。

### 表書きの早見表

| 時期・宗派 | 表書き |
|---|---|
| 通夜・葬儀（仏式・宗派がわからない） | 御霊前 |
| 通夜・葬儀（浄土真宗） | 御仏前 |
| 四十九日の法要以降（仏式） | 御仏前 |
| 仏式全般（時期を問わず使える） | 御香典・御香料 |
| 神式 | 御玉串料・御榊料・御神前 |
| キリスト教式 | お花料・御花料 |

### なぜ「御霊前」と「御仏前」が分かれるのか

仏教では、亡くなった方は四十九日をかけて次の生へ向かうと考えられています。
その間はまだ「霊」なので**御霊前**、四十九日を過ぎて仏になってからは**御仏前**、
という区切りです。

浄土真宗が例外なのは、**亡くなってすぐ仏になる（往生即成仏）** という教えのため。
最初から「御仏前」になります。

宗派がわからないときは、**「御香典」または「御霊前」** にしておくと角が立ちにくい、
といわれます。宗派を確かめきれないときは「御香典」が無難です。

### 薄墨で書くのはいつまで？

通夜・葬儀の香典は**薄墨**で書くのがならわしとされます。
「突然のことで墨をする間もなかった」「涙で墨が薄まった」という気持ちを表したもの、
と説明されることが多いです。

四十九日以降の法要は、あらかじめ日取りがわかっているものなので、
**普通の濃さの墨（黒）** で書いて差し支えないとされます。

薄墨の筆ペンはコンビニや文具店で売っています。手元になければ、
無理に薄く書こうとするより普通の筆ペンで丁寧に書くほうがよい、という考え方もあります。

### 水引の選び方

| 場面 | 水引 |
|---|---|
| 通夜・葬儀・法要 | 黒白または双銀の**結び切り** |
| 関西・北陸の一部 | 黄白の結び切り（法要以降に使う地域がある） |
| 結婚 | 紅白または金銀の**結び切り**（10本） |
| 出産・入学・新築 | 紅白の**蝶結び（花結び）** |
| 快気祝い・お見舞い | 紅白の**結び切り** |

**結び切り**はほどけない結び方で、「二度とあってほしくないこと」に使います。
弔事のほか、結婚と快気祝いもこちら。

**蝶結び**は何度でも結び直せるので、「繰り返してよいこと」に使います。
出産・入学・長寿のお祝いなど。

包む金額が少額（5,000円程度まで）のときは、水引が印刷された封筒でも失礼にあたらない、
とされています。

### 中袋の書き方

- **表**: 金額を縦書きで。旧字体（大字）を使うのがならわしとされます
- **裏**: 郵便番号・住所・氏名。受け取った側が香典返しの宛先として使います

金額の旧字体はこちら。

| 数字 | 旧字体 | 書き方の例 |
|---|---|---|
| 3,000 | 参仟 | 金参仟円 |
| 5,000 | 伍仟 | 金伍仟円 |
| 10,000 | 壱萬 | 金壱萬円 |
| 30,000 | 参萬 | 金参萬円 |
| 50,000 | 伍萬 | 金伍萬円 |
| 100,000 | 拾萬 | 金拾萬円 |

「也」を付けるかどうかは、どちらでもよいとされます。

中袋がないタイプの香典袋のときは、**外袋の裏の左下**に住所と金額を書きます。
書く欄が印刷されていることもあります。

### お札の入れ方

香典では、**お札の肖像が裏側・下向き**になるように入れるといわれます。
顔を伏せることで悲しみを表す、という説明がされます。

**新札は避ける**のがならわしです。「不幸を予期して用意していた」と受け取られないため、
とされています。手元に新札しかないときは、**一度折り目をつけてから**入れます。

逆に、**ご祝儀は新札**を用意し、肖像が表・上向きになるように入れます。
慶事と弔事でちょうど反対になる、と覚えると迷いません。

### 4と9のつく金額を避ける

香典では **4（死）・9（苦）** を連想させる金額を避けるといわれます。
4,000円、9,000円、4万円などです。

また、割り切れる数は「縁が切れる」に通じるとして、
**奇数**にするという考え方もあります（ただし2万円は「ペア」と解釈して許容する見方もあり、
このあたりは地域や家によって差があります）。

### 連名で包むとき

- **3名まで**: 中央に代表者、左へ向かって目上順に並べます
- **4名以上**: 「〇〇部一同」などとまとめ、**別紙に全員の氏名と金額**を書いて中袋に入れます

一人あたりの金額が端数になるときは、切りのよい数字に合わせて集めるほうが、
受け取る側も記録しやすくなります。

### 渡すときに添える言葉

長い挨拶は求められていません。

- 通夜・葬儀: 「この度はご愁傷さまでございます」「心よりお悔やみ申し上げます」
- 受付では、袱紗（ふくさ）から出して**表書きが相手から読める向き**にして両手で渡します

「重ね重ね」「たびたび」「再び」などの**重ね言葉**は、不幸が繰り返されることを連想させる
として避けるといわれます。
