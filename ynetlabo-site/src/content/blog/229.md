割り勘アプリ **wa/ri** を使った人が、2,000人を超えました。

![wa/ri を使った人の数の推移（2025年5月〜2026年9月9日の累計）](/images/posts/wari-users-229.svg)

線が途中から立ち上がっているのが分かると思います。
**2026年に入ってからの1,305人が、2025年の合計848人を上回りました。**

使ってくださっている方、そして招待リンクを回してくださった方に、
まずお礼を申し上げます。ありがとうございます。

### いちばん開かれるのは、週末の夜です

アプリが開かれるのがいちばん多いのは**日曜**で、次が土曜。
**土日のふたつで、全体の4割近く**を占めます。
時間帯は、**夜9時から日付が変わるころ**にかけてが山になります。

思い当たる場面があると思います。

- 旅行から帰ってきて、まだ荷ほどきも済んでいない日曜の夜
- 飲み会が終わって、電車の中で「結局いくらだったっけ」となる帰り道

wa/ri がいちばん開かれているのは、この時間です。
**楽しかったことの、いちばん最後に残る面倒**が割り勘なのだと思います。

誰がいくら立て替えたかをその場で入れておけば、
最後に「**誰が誰にいくら払えば終わりか**」が出ます。
結果の数字だけでなく、そこに至る計算の過程まで見せるようにしています。
金額の話は、根拠が見えないと納得しにくいからです。

### 1,108のルームに、6,084の記録

これまでに作られたルームは、**1,108**。
ひとつひとつが、誰かの飲み会であり、旅行です。

そこに記録された支払いは、**6,084件**になりました。
ひとつのルームにつき、平均で5件から6件。
飲み会なら一次会と二次会、旅行なら宿と交通と食事、
というくらいの粒度で残されている計算になります。

そのなかには、**韓国ウォン・ユーロ・中国元・米ドル・英ポンド・香港ドル・タイバーツ**で
作られたルームもありました。日本円を入れて、8つの通貨です。

外貨ルームは、現地通貨のまま記録して、最後に精算できる機能です。
レートと円が混ざる海外旅行の精算はいちばん面倒な部類なので、
旅先で開いてもらえているのはうれしいところです。

### いちばん押されているのは、結果を見比べるボタンでした

もっとも多く使われているのは、**割り勘の結果画面で表示を切り替える操作**でした。
これまでに**2,826回**。内訳を開いたり、ひとまとめにしたり、
支払いのない人を隠したり、という操作です。

出た金額をそのまま受け取るのではなく、
**どういう計算でその数字になったのかを確かめている**ということだと思います。
wa/ri でいちばん時間をかけて作ったのがこの画面なので、
ここが最も押されているのは、作った側としてうれしい結果でした。

次に多いのがメンバーの登録で、2,242回。
割り勘の結果をそのまま画像にして送る機能も、179回使われています。

### 広めてくれたのは、招待リンクでした

新しく使い始めた方の**およそ7割**は、
友達や同僚が送った招待リンクから入ってきています。

広告はほとんど出していません。
検索やランキングでもなく、**実際の飲み会や旅行の場で、
幹事の誰かがリンクを1本送ってくれた**。それが増えた理由のほぼすべてです。

いちばん多いのは Web 版からの利用で、次いで iOS、Android の順です。
**アプリを入れなくても、招待リンクを開けばその場で使えます。**
「まずアプリを入れて」とお願いしなくていいのは、幹事にとって地味に効くところだと思います。

### 忘年会に向けて、機能が増えました

この夏から秋にかけて、こんな機能が増えています。

- **明細割り** … 1回のお会計を品目ごとに分けて、食べた人だけで割れます
- **レシート読み取り** … レシートを撮るだけで、日付・店名・明細が入ります（iOS / Android）
- **PDFレポート** … 記録を3章立ての1枚にまとめて、印刷したり配ったりできます

明細割りとレシート読み取りは9月に公開したばかりですが、
**公開から9日間で、明細割りが38回、レシートの読み取りが26回**使われました。
さっそく手に取っていただいています。

詳しくは[9月のアップデート情報](/archives/227/)にまとめています。

### 年末の幹事をやる予定の方へ

これから忘年会と、年末年始の旅行の季節です。
**先にルームだけ作っておくと、当日がずいぶん楽になります。**

記録するのは幹事ひとりでなくて構いません。
招待リンクを送っておけば、各自が自分の払った分を入れられます。
一次会と二次会で払った人が違っても、最後にまとめて精算できます。
